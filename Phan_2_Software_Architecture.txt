Personal Light Novel Reader (iOS Native)

1. Kiến trúc tổng thể

Áp dụng Clean Architecture kết hợp MVVM và Protocol-Oriented
Programming.

Các tầng: - App - Presentation - Domain - Data - Infrastructure

Mỗi tầng chỉ phụ thuộc vào tầng bên trong.

2. Modules

-   Authentication
-   Reader
-   Editor
-   GoogleDocs
-   GoogleDrive
-   Sync
-   TTS
-   Search
-   Bookmark
-   History
-   Settings
-   Cache
-   Database
-   Networking
-   Logging

3. Folder Structure

App/ Presentation/ Features/ Shared/ Domain/ Entities/ UseCases/
Repositories/ Data/ RepositoryImpl/ Local/ Remote/ Infrastructure/
Network/ Google/ Audio/ Storage/

4. Dependency Injection

Sử dụng protocol cho mọi service và inject qua initializer. Không sử
dụng singleton trừ các dịch vụ hệ thống thực sự cần thiết.

5. Repository Pattern

Domain chỉ biết Repository protocol. Data triển khai Repository bằng
Local + Remote.

6. State Management

-   @Observable/@State
-   ViewModel cho từng màn hình
-   Async/Await
-   Không để business logic trong View.

7. Networking

-   URLSession
-   Async/Await
-   Retry
-   Token Refresh
-   Reachability
-   Centralized Error Mapping

8. Database

Ưu tiên SwiftData. Có thể thay CoreData nếu cần. Lưu: - Cache chương -
Bookmark - Reading History - Pending Sync

9. TTS Architecture

Adapter Pattern: TTSProvider protocol - OpenAIProvider - AzureProvider -
EdgeProvider - AVSpeechProvider

Reader chỉ giao tiếp qua protocol.

10. Sync Engine

Hai chiều: Google Docs <-> Local Database

Conflict Resolution: - Last Modified - Manual Merge - Retry Queue

11. Logging

Unified Logger: - Network - Sync - TTS - Database - UI

12. Error Handling

Chuẩn hóa AppError: - Network - Auth - GoogleAPI - Sync - Storage -
Validation

13. Coding Standards

-   Swift 6
-   SOLID
-   DRY
-   KISS
-   YAGNI
-   SwiftLint
-   SwiftFormat
-   Documentation

14. Scalability

Kiến trúc phải cho phép bổ sung: - EPUB - PDF - OCR - AI Translation -
Apple Intelligence - Multi-source Library mà không cần thay đổi các
module hiện có.

Đây là khung kiến trúc của dự án. Các phần tiếp theo sẽ đi sâu vào từng
module (Authentication, Google Docs, Reader, Editor, TTS, Sync…) với đặc
tả chi tiết.
