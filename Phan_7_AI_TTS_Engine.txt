Personal Light Novel Reader (iOS Native)

1. Mục Tiêu của AI Text-to-Speech (TTS) Engine
------------------------------------------------------------------------
Module AI TTS đóng vai trò thiết yếu, chuyển đổi trải nghiệm đọc thông thường thành trải nghiệm "nghe truyện" (Audiobook). Hệ thống yêu cầu khả năng phát nền (Background Playback), hỗ trợ nhiều nhà cung cấp giọng đọc (TTS Providers) với độ trễ thấp, và quan trọng nhất là phải đồng bộ hóa (sync) chính xác từng câu đang đọc với giao diện Reader để highlight nội dung và tự động cuộn trang.

2. Kiến Trúc Tổng Thể (Adapter Pattern)
------------------------------------------------------------------------
Để dễ dàng mở rộng và không bị phụ thuộc vào một API cụ thể nào, hệ thống TTS được thiết kế dựa trên Adapter Pattern. Mọi tương tác từ UI/ViewModel đều thông qua một protocol duy nhất là `TTSProvider`.

* Core Components:
- `TTSManager`: Singleton hoặc Service quản lý trạng thái phát (Play, Pause, Stop), quản lý Audio Session, và điều phối các `TTSProvider`.
- `TTSProvider`: Giao diện (Protocol) định nghĩa các hàm cơ bản (synthesize, play, pause).
- `TextSegmenter`: Chịu trách nhiệm chia nhỏ toàn bộ chương truyện (Chapter) thành các đoạn văn (Paragraph) và câu (Sentence) để nạp vào TTS engine.
- `AudioCacheManager`: Tải trước (Pre-fetch) âm thanh của các câu tiếp theo và lưu trữ đệm (Cache) trên ổ đĩa để phát mượt mà không bị giật lag khi mạng chậm.

3. Chi tiết Giao diện (Protocols & Interfaces)
------------------------------------------------------------------------
```swift
public enum TTSState: Equatable {
    case idle
    case loading(sentenceIndex: Int)
    case playing(sentenceIndex: Int)
    case paused(sentenceIndex: Int)
    case error(Error)
}

public protocol TTSProvider {
    var providerName: String { get }
    var currentVoice: TTSVoice { get set }
    var speakingRate: Float { get set }
    
    // Yêu cầu synthesize một câu (không phát, chỉ tải về)
    func synthesize(text: String) async throws -> URL
    
    // Phát file âm thanh từ URL cục bộ
    func play(audioURL: URL) async throws
    func pause()
    func resume()
    func stop()
}
```

4. Quản lý Audio Session & Background Playback
------------------------------------------------------------------------
Bắt buộc phải xin quyền và thiết lập `AVAudioSession` để app có thể phát âm thanh khi màn hình tắt hoặc khi người dùng chuyển sang app khác.

- Thêm `UIBackgroundModes` -> `audio` vào Info.plist.
- Cấu hình AVAudioSession:
```swift
let session = AVAudioSession.sharedInstance()
try session.setCategory(.playback, mode: .spokenAudio, options: [.duckOthers])
try session.setActive(true)
```
- Tích hợp `MPRemoteCommandCenter` để xử lý các nút bấm từ tai nghe Bluetooth, màn hình khóa (Lock Screen), và Control Center:
  + Nút Play/Pause.
  + Nút Next/Previous Track (Được map thành Next/Previous Sentence).
- Cập nhật `MPNowPlayingInfoCenter`: Hiển thị tên truyện, tên chương hiện tại, và artwork (ảnh bìa) lên màn hình khóa.

5. Thuật toán Xử lý và Phân mảnh Văn bản (Text Segmentation)
------------------------------------------------------------------------
Nguyên lý: Các API như OpenAI TTS hoặc Azure có giới hạn độ dài ký tự trong một request, đồng thời để UI có thể highlight chính xác câu đang đọc, ta KHÔNG THỂ gửi toàn bộ chương cho API. Ta phải chia (split) chương thành các câu nhỏ.

- Input: `String` (Toàn bộ chương, ví dụ: 20,000 ký tự).
- Output: `[Sentence]` (Mảng các struct chứa nội dung câu, vị trí bắt đầu `startIndex` và `endIndex` trong chuỗi gốc).
- Rules phân tách (Regex/Linguistic Tagger):
  + Tách tại các dấu chấm `.` , chấm hỏi `?` , chấm than `!`.
  + Phải bảo toàn các đoạn hội thoại nằm trong ngoặc kép `" "` hoặc `「 」` (ngoặc của Light Novel Nhật).
  + Xóa bỏ các ký tự ẩn (invisible characters) không cần thiết để giảm tải API.

6. Cơ chế Tải Trước (Pre-fetching) và Lưu Trữ (Audio Cache)
------------------------------------------------------------------------
Để loại bỏ độ trễ (latency) giữa các câu, hệ thống sử dụng một hàng đợi (Queue).
- Giả sử hệ thống đang phát Câu 1.
- `AudioCacheManager` sẽ kích hoạt async task để gọi API synthesize cho Câu 2, Câu 3 và Câu 4.
- File âm thanh trả về được lưu vào thư mục `NSTemporaryDirectory()` hoặc Cache directory của ứng dụng.
- Khi Câu 1 kết thúc, `AVPlayer` hoặc `AVAudioEngine` ngay lập tức nhận URL của Câu 2 để phát. Đạt được trải nghiệm đọc liên tục (Gapless playback).
- Xóa Cache: Các file âm thanh đã phát xong sẽ tự động bị xóa sau khi kết thúc chương để tiết kiệm dung lượng thiết bị.

7. Tích hợp và Đồng bộ với Reader Engine
------------------------------------------------------------------------
TTSManager sử dụng cơ chế Reactive (Combine / AsyncStream / Observation) để báo cáo trạng thái.
- `ReaderViewModel` lắng nghe biến `ttsState`.
- Khi `ttsState` = `.playing(sentenceIndex: 5)`:
  + Tìm đoạn range của câu thứ 5 trong `NSAttributedString` của Reader.
  + Áp dụng background color (Highlight) cho range đó.
  + Kích hoạt tính năng Auto-Scroll (Cuộn tự động): Tính toán khung hình (Bounding Rect) của đoạn text vừa được highlight, so sánh với kích thước của ScrollView hiện tại. Nếu đoạn text nằm ở nửa dưới của màn hình, kích hoạt `scrollView.setContentOffset` cuộn mượt mà (animated) xuống.

8. Xử lý Lỗi và Edge Cases
------------------------------------------------------------------------
- Mất kết nối mạng (Network Drop): Nếu đang sử dụng Cloud TTS (OpenAI, Azure) và rớt mạng, `TTSManager` phải bắt lỗi (Catch error), tự động Fallback (chuyển đổi dự phòng) sang `AppleAVSpeechProvider` (TTS Offline có sẵn trên iOS) để việc nghe không bị gián đoạn, đồng thời hiện một thông báo toast nhỏ: "Đã chuyển sang giọng đọc ngoại tuyến".
- Lỗi API Hết Hạn Mức (Rate Limit - HTTP 429): Xử lý bằng Exponential Backoff, đợi 2s, 4s, 8s rồi thử lại trước khi fallback.
- Ngắt quãng do Cuộc Gọi (Interruption): Lắng nghe notification `AVAudioSession.interruptionNotification`. Khi có cuộc gọi tới -> Pause. Cuộc gọi kết thúc -> Tự động Resume nếu hệ thống cho phép.

9. Các TTS Engine (Provider) Hỗ trợ
------------------------------------------------------------------------
1. **Apple AVSpeechSynthesizer**: Mặc định, miễn phí, hoạt động offline. Hỗ trợ các giọng Premium cài đặt trong iOS Settings.
2. **OpenAI TTS**: Giọng đọc tự nhiên, ấm áp (Alloy, Echo, Fable, Onyx, Nova, Shimmer). Chi phí tính theo ký tự. Tốc độ rất nhanh, hỗ trợ API endpoint `v1/audio/speech`.
3. **Azure Cognitive Services TTS**: Rất đa dạng ngôn ngữ, bao gồm giọng đọc Tiếng Việt (Hoài My, Nam Minh) rất chuẩn xác, cấu hình được emotion và SSML.
4. **Edge TTS**: Tùy chọn (dựa trên các endpoint web của Microsoft Edge).

10. Tiêu chí Hoàn thành (Acceptance Criteria)
------------------------------------------------------------------------
- [ ] Âm thanh phát nền liên tục, không bị ngắt quãng khi khóa màn hình.
- [ ] Control Center hiển thị đúng bìa truyện và tiến trình câu.
- [ ] Chuyển đổi mượt mà giữa các provider mà không văng app.
- [ ] Mất mạng có thể tự nhảy sang giọng Offline.
- [ ] Tự động cuộn trang (Auto-Scroll) và highlight chuẩn xác tới 99% theo từng câu.
- [ ] Không có memory leak khi sử dụng AVPlayer sinh ra hàng ngàn URL cho một chương truyện dài.
